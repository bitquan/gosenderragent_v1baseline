# Owner Docs

Start here if you want to run, use, update, and supervise the GoSenderr Desktop Agent without digging through repo internals.

Files in this folder:

- `01_desktop_app_complete_guide.md`
  Desktop app setup, chat workflow, monitor, settings, and the safest day-to-day loop.
- `02_vscode_companion_complete_guide.md`
  How to use the VS Code companion with the same bounded engine loop.
- `03_download_release_and_update_guide.md`
  How to build, find, stage, and install the latest Windows release.

Recommended order:

1. Read `01_desktop_app_complete_guide.md`
2. Read `02_vscode_companion_complete_guide.md`
3. Use `03_download_release_and_update_guide.md` when you want the latest installer or staged release
