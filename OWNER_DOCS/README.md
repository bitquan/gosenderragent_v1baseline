# Owner Docs

Start here if you want to run, use, update, and supervise the GoSenderr Desktop Agent without digging through repo internals.

Files in this folder:

- `01_desktop_app_complete_guide.md`
  Desktop app setup, chat workflow, monitor, settings, and the safest day-to-day loop.
- `02_vscode_companion_complete_guide.md`
  How to use the VS Code companion with the same bounded engine loop.
- `03_download_release_and_update_guide.md`
  How to build, find, stage, and install the latest Windows release.
- `04_chat_modes_and_agent_control.md`
  What `Ask`, `Plan`, `Edit`, and `Agent` mean and when the engine is allowed to act.
- `05_git_workflow_and_releases.md`
  How to use the desktop Git workspace, publish `codex/*` branches, and cut `desktop-v*` releases.
- `06_terminal_engine_workflow.md`
  How to drive the canonical engine, Git, review, and readiness flow from the terminal first.
- `07_autonomous_clone_workflow.md`
  How to run the engine in a self-host clone, verify real clone-only edits, and stop active work safely.
- `08_preferred_vs_compatibility_paths.md`
  Which engine paths are the preferred baseline for new work, and which legacy compatibility paths should stay debug-only.

Recommended order:

1. Read `01_desktop_app_complete_guide.md`
2. Read `02_vscode_companion_complete_guide.md`
3. Read `04_chat_modes_and_agent_control.md`
4. Read `05_git_workflow_and_releases.md`
5. Read `06_terminal_engine_workflow.md`
6. Read `07_autonomous_clone_workflow.md`
7. Read `08_preferred_vs_compatibility_paths.md`
8. Use `03_download_release_and_update_guide.md` when you want the latest installer or staged release
